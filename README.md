# Binder Lookup

Find where a card goes in a 4×4 (16-pocket) TCG binder.

Open `index.html` in a browser, type a card number or a Pokémon name, and press Enter. It shows the page, the sheet, and the two-sheet spread of the open binder with the card highlighted. Use Prev/Next to flip through pages.

- **Sheet**: one 4×4 face of 16 cards. Sheet 1 holds cards 1–16, sheet 2 holds 17–32, and so on.
- **Page**: one physical page, with a sheet on the front and one on the back. Page 1 is sheets 1–2, page 2 is sheets 3–4.

Pokémon names map to their National Pokédex number (#1–#1025). The list is stored in `index.html`, so the page works offline.
